# Tourist Spot Website

## Project Description

A user-friendly website designed to help users explore
different tourist destinations and travel information.

## Technologies Used

- HTML
- CSS
- JavaScript
- Java

## Features

- Explore tourist destinations
- View tourist place information
- User-friendly interface
- Attractive destination images
- Easy navigation

## Project Purpose

The main purpose of this project is to provide users
with an easy way to explore tourist destinations.
